Skinning system

To rebrand this entire shell, swap the 5 token groups below. Every component reads from CSS custom properties — change the value once, every surface, border, text label, and accent updates. That's the discipline of a surface-ladder system: elevation comes from opacity-lifted layers, not box-shadows.

Brand — single accent rule

One chromatic color per viewport. The accent never fills a card, never pairs with a second accent. Used at: brand mark, primary CTA, focus ring, active state, link emphasis only.

Skinning recipe — drop this into globals.css
/* Skin this whole shell by changing only these 4 values */ :root { --bg: #08090a; /* canvas */ --surface-1: #0f1011; /* panel */ --ink-1: #f7f8f8; /* primary text */ --accent: #5e6ad2; /* brand — change ONE hue */ } /* Result: every surface, border, dot, and CTA updates. No component code changes. No per-instance overrides. */
