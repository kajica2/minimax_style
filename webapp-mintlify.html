Install the SDK

One package, three runtimes. The SDK handles auth, retries, and streaming — you focus on the model call.

npm install minimax
2

Pass your API key

Set it once as an env var. The SDK reads it on every call — no need to thread it through your codebase.

MINIMAX_API_KEY=mmx-…
3

Make your first request

Pick a model, write a message, stream the response. The output is OpenAI-compatible, so existing tooling works.

await client.chat.completions.create(…)
