Skinning system — terminal-born, border-driven

Supabase-style systems deliberately avoid shadows in dark mode — they don't read. Depth is communicated through a 3-step border hierarchy, plus the green accent border at 30% opacity for the elevated/active state. To rebrand this entire shell, change the 4 groups below.

Surfaces — three dark plates
--bg
#0f0f0f · canvas
--bg-2
#171717 · panel
--bg-3
#1c1c1c · row
--bg-4
#232323 · raised
Borders — three steps, not shadows
--border-subtle
#242424 · hint
--border
#2e2e2e · default
--border-strong
#393939 · prominent
--border-accent
rgba(62,207,142,0.3) · elevated
Brand — one emerald, always 30% on the elevated border
--accent

--accent-soft
rgba(62,207,142,0.12) · bg
Skinning recipe
/* Skin this whole shell by changing 4 values. The border hierarchy is the depth signal — not shadows. */ :root { --bg: #0f0f0f; /* canvas */ --border: #2e2e2e; /* default border = depth */ --accent: #3ecf8e; /* brand — one chromatic */ --font-mono: "JetBrains Mono", monospace; } /* Result: every border, every status pill, every SQL keyword color, every connection badge updates. The 3-step border hierarchy reads as depth without a single shadow. */
