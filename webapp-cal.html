Skinning system — white + black, the Cal way

Cal.com's design discipline is restraint. White canvas, near-black primary CTA, light-gray surface cards. The featured pricing card flips to dark — the only dark card on light pages. To rebrand this scheduling app, change the 4 groups below. The single primary CTA per band is the rule.

Surfaces — white + one light gray

--surface-2
#f5f5f5 · card
--surface-3
#ebebeb · inset
--primary

Skinning recipe
/* Skin this scheduling app by changing 4 values. The dark CTA is the brand identity. No gradients. */ :root { --bg: #ffffff; /* canvas */ --surface-2: #f5f5f5; /* card surfaces */ --ink-1: #111111; /* display + primary CTA */ --font-display: "DM Sans", "Cal Sans", sans-serif; } /* Result: every primary button goes dark, every featured pricing card flips to dark, every terminal block goes dark, every display headline re-weights. White stays white. */
