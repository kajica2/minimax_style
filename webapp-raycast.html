Skinning system — command-cockpit in 4 tokens

Raycast is dark-only by design. The single warm coral accent is the entire brand identity — gradients are used once per page maximum, on the workspace glyph and the active selection marker. Barely-visible elevation steps replace shadows. To rebrand this command-cockpit, change the 4 groups below.

Canvas — five dark steps, no shadows
--bg
#040506 · canvas
--surface
#131418 · panel
--surface-2
#1c1e23 · row
--surface-3
#25282e · selected
Accent — single warm coral, one gradient
--accent
#ff6363 · brand
--gradient
135° · coral→orange
--accent-soft
rgba 14% · bg
Skinning recipe
/* Skin this command-cockpit by changing 4 values. The coral gradient is the entire brand identity. */ :root { --bg: #040506; /* near-black canvas */ --surface: #131418; /* command bar surface */ --accent: #ff6363; /* coral — single chromatic */ --gradient: linear-gradient(135deg, #ff6363, #ff8b3d); } /* Result: every selected row, every active tab, every quick-action icon, every recent badge, every ⌘K pill picks up the new gradient. Used once per page. */
