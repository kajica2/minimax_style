Skinning system — sage + hidden orange

PostHog is the anti-corporate of dev tools. The sage/olive palette rejects conventional blue; the brand orange is the hidden signature that only appears on hover. To rebrand this analytics shell, change the 4 groups below. The orange-on-hover rule is the brand identity.

Brand — hidden orange on hover

Skinning recipe
/* Skin this analytics shell by changing 4 values. The orange is HIDDEN — never on default state, only on hover. */ :root { --canvas: #fbf9f3; /* warm parchment, NOT white */ --ink-1: #23251d; /* deep olive, NOT pure black */ --orange: #f54e00; /* hidden — only on hover */ --font-display: "Bricolage Grotesque"; } /* Result: every insight name goes orange on hover, every active sidebar item has the orange bar, every stat card reveals an orange underline on hover. Default state stays calm sage + olive. The orange is the surprise. */
